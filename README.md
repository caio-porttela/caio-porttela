## 🚀 Projeto em destaque

### 🔐 AWS Secure Infrastructure Lab

Meu laboratório prático de infraestrutura e segurança na AWS.

Neste projeto, explorei a configuração e a interação entre serviços de nuvem, banco de dados, permissões e conectividade.

**Principais serviços e conceitos explorados:**

- Amazon EC2 — computação em nuvem.
- Amazon RDS for PostgreSQL — banco de dados relacional gerenciado.
- Amazon S3 — armazenamento de objetos.
- AWS IAM — identidade, permissões e controle de acesso.
- AWS Systems Manager Session Manager — acesso administrativo à instância.
- Security Groups — controle do tráfego de rede.
- AWS CLI — interação com serviços AWS pela linha de comando.

Também documentei a arquitetura, os controles de segurança e os testes realizados, incluindo situações de acesso negado e validação de conectividade.

🔗 **[Acessar o projeto no GitHub](https://github.com/caio-porttela/aws-secure-infrastructure-lab)**
